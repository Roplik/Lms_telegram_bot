---

## 📌 Описание проекта

**Com-X Downloader Bot** — асинхронный Telegram-бот, предназначенный для авто-поиска, загрузки и выгрузки глав манги и комиксов с сайта `com-x.life`. Бот автоматизирует парсинг страниц, выкачивание файлов `.cbr` и их последующее сохранение на **Google Drive** с предоставлением прямых ссылок пользователю.

---

## ⚙️ Реализованный функционал

- 🔍 **Многостраничный асинхронный поиск:**  
  Парсинг каталога и пагинации сайта по поисковому запросу с параллельной обработкой страниц через Playwright (`asyncio.Semaphore`).
- 🖼 **Интерактивная галерея и навигация:**  
  Отображение постеров манги, названий и ссылок в формате инлайн-карточек в Telegram с возможностью листания результатов («Назад» / «Вперед»).
- 📥 **Пакетное скачивание (Scraping):**  
  Автоматический перебор глав, отслеживание progress-bar'а выкачивания и сохранения файлов `.cbr` в локальную директорию.
- ☁️ **Интеграция с Google Drive:**  
  Создание папки на Диске, потоковая загрузка `.cbr` архивов, авто-настройка прав доступа (`reader` по ссылке) и выдача итоговой папки пользователю.
- ⚡ **Кеширование и оптимизация:**  
  Сохранение метаданных манги, постеров и идентификаторов папок Google Drive в JSON-кеш для мгновенной повторной выдачи без повторного парсинга.
- 🧹 **Автоматический клин-ап:**  
  Фоновая задача (Background Scheduler) для безопасного удаления старых временных локальных файлов и автоматической очистки устаревших папок на Google Drive.

---

## 🛠 Технологический стек

- **Language:** Python 3.x (`asyncio`)
- **Telegram Framework:** `aiogram 3.x` (FSM, Inline Keyboards, Callback Routing)
- **Web Scraping & Browser Automation:** `playwright` (Firefox Headless mode)
- **Cloud API Integration:** `pydrive` (Google Drive API v3)
- **Data Persistence & Cache:** JSON state storage, MD5 hashing для callback-data и ключей кеша
